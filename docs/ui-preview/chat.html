出口沙特的 LED 装饰灯串主要涉及 SABER 认证，并需同时满足 SASO 安规与能效要求：

  • 产品符合性证书 PC：出货前按批次在 SABER 平台注册，需提供测试报告与符合性声明1
  • 装运符合性证书 SC：每批货出运前申请，与 PC 绑定，清关时随箱13
  • 能效与标签：灯串属受管制电器，需 SASO 2870 能效测试并加贴能效标签2
